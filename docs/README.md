# Documentação de Requisitos — Sistema Dsilk

## 1. Apresentação

Este diretório reúne os artefatos produzidos pelo responsável dos requisitos para o desenvolvimento do sistema Dsilk.

A documentação contempla a especificação dos requisitos funcionais e não funcionais, a modelagem dos casos de uso, as regras de negócio, os perfis de acesso, o mapeamento das rotas da API e a matriz de rastreabilidade.

Este README funciona como índice central da documentação, apresentando a estrutura dos arquivos e facilitando o acesso aos artefatos produzidos.
